# Publications 封面 + 期刊指标更新（2026-11-15）

本项目基于上一版 29 篇论文和 5 条 News 的网站，保留前端编辑、中英文切换、筛选。

## 影响因子口径
- **2025 Journal Impact Factor**：2026 年 JCR 正式公布的 2025 年数据。
- **JCR Q1–Q4**：JCR 2026，2025 JIF 学科分区。跨学科期刊展示最优类别分区，仅作为简明网页呈现。
- **CAS 2025**：历史中科院期刊分区，只有二次检索确认后才填写，与 JCR Q 不等价，未确认不显示。
- **2026E 非官方趋势估算**：网页上默认隐藏，访客可手动开启。仅根据 2024 与 2025 两个年度 IF 以 50% 斜率保守外推，并将变化限制为 2025 JIF 的 ±10%；该方法不是引文级预测模型，也不是 2027 年 JCR 的官方值，不能用于学术评价。若无上一年数据，则为 —。
- `Annals of Translational Medicine` 的 SCIE 收录于 2023 年终止，因此 2025 JIF 显示 —，不能沿用历史影响因子。
- 指标引用出处和更新时间见 `journal_metrics.json`。

## 封面规则
- 有核实的当期封面，优先使用。
- 无独立卷期封面的 OA 期刊，显示找到的期刊正式封面图；没有可信封面地址的，不伪造官方封面。
- 期刊封面可能因出版社防盗链而加载失败，网页会自动显示期刊名称作为占位，不显示“Cover pending”字样。
- 用于期刊视觉代表的其他年份封面并不代表作者论文被选为该封面，更多信息见 `cover_sources.json`。
- 如需离线稳定显示，需将得到出版社授权且可访问的图片下载到仓库 `assets/covers/`，再通过前端编辑更新图片路径。

## GitHub Pages 上传
1. 下载 `index.html` 并替换 `liangyuan-njmu.github.io` 仓库根目录的旧版；或上传本压缩包内同名文件。
2. 在 `main` 分支提交，检查 Settings → Pages 和 Actions，部署完成后访问 `https://liangyuan-njmu.github.io/?v=20261115jifcover1`。
3. 29 篇论文都应出现 2025 IF（部分暂无）、JCR Quartile（有来源才显示）和可选 2026E。
4. 编辑器中 Metrics 选项卡可手工修正期刊指标并导出新 HTML。

注意：网页上的 IF 属于期刊层面指标，不能衡量单篇论文质量。
